IPL BATSMAN ANALYTICS AND PREDICTION DASHBOARD

REQUIREMENTS:
- Windows 10/11
- Python 3.10 or newer
- Internet connection for initial package installation

HOW TO RUN:
1. Extract the ZIP folder.
2. Open the extracted IPL_Streamlit_Dashboard folder.
3. Double-click Run_Dashboard.bat.
4. Wait for packages to install.
5. Open the URL displayed in the terminal, usually:
   http://localhost:8501

To stop the dashboard, press CTRL+C in the terminal.

NOTE:
Keep the data folder and app.py together.
